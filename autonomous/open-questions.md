# Bounded open questions

Work on one question at a time and mark its result in `research-ledger.md`.

1. Does a targeted repository contradiction remain after Checkpoint AL?
2. Can a cheap deterministic check verify a specific census or artifact scalar without reopening
   an old experiment?
3. Does a legitimate public source select a period, inheritance rule, recurrence, permutation,
   fractionation readout, or alignment for an AL conditional class?
4. Is there a narrowly scoped, admissible primary-source reference that resolves an existing
   provenance gap without exposing solution material?
5. Has later evidence prospectively resolved an old UNKNOWN while leaving historical documents
   unchanged?

Do not turn these into broad searches. A question is complete when its evidence and novelty class
are recorded, including a negative result.
