# Contributing a result

Open a change only with a complete experiment record. Include input provenance, normalization, code, fixed parameter bounds, total trials, and all crib outputs. Do not commit large generated candidate dumps; store a compact hash and reproducible regeneration path instead.

Label conclusions as `negative`, `inconclusive`, `replicated`, or `candidate`. Use `candidate` only when the mechanism was specified without fitting the released plaintext and exactly reproduces all declared cribs.
