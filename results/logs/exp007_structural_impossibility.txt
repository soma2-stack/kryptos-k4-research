## 1. Reflector-based rotor machines (Enigma family)  -> ELIMINATED
   Invariant: a machine with a reflector can never encipher a letter to itself.
   Observed fixed points C[i] == P[i]: [(32, 'S'), (73, 'K')]
   2 violations. Any reflector machine is impossible.
   (2 fixed points in 24 letters is unremarkable for a general cipher -
    expected 24/26 = 0.92 - so this eliminates reflectors, nothing more.)

## 2. Playfair  -> ELIMINATED
   Invariant: Playfair cannot output a doubled letter. If P1,P2 lie in one
   row or column the outputs are distinct neighbours; otherwise the
   rectangle rule gives cells (r1,c2) and (r2,c1), equal only if P1 == P2,
   which Playfair forbids inside a digraph.
   alignment 0: doubled ciphertext digraphs from distinct plaintext: [(32, 'ST', 'SS')]
   alignment 1: doubled ciphertext digraphs from distinct plaintext: [(25, 'NO', 'QQ'), (67, 'IN', 'TT')]
   Both digraph alignments are violated, so no prepended null rescues it.

## 3. Monoalphabetic substitution  -> ELIMINATED
   10 conflicting position-pairs share a ciphertext letter but differ in plaintext.

## 4. Pure transposition, of any complexity  -> ELIMINATED
   Invariant: a transposition permutes letters, so it preserves the letter
   multiset and therefore the index of coincidence exactly.
   K4 IoC = 0.03608
   IoC of 97 letters drawn from English unigram frequencies:
     mean 0.06558, sd 0.00763, 20000 simulations
   simulations at or below K4's IoC: 0/20000  (p = 0.00000)
   z = -3.87. Real English scores HIGHER than unigram-random,
   so this bound is conservative: the true p is smaller still.
   K4 cannot be an anagram of English. Every route, columnar, spiral and
   grid transposition applied alone is therefore dead, without enumeration.
